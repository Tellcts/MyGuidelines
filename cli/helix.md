## 1. 简介

欢迎使用 Helix 编辑器！Helix 是一个**模态**编辑器，这意味着它有不同的模式用于编辑文本。

主要模式：

- **普通模式（Normal mode）** — 按键不输入文本，而是执行各种操作
- **插入模式（Insert mode）** — 按键输入文本
- **选择模式（Select mode）** — 扩展选择区

这种模式设计让你可以更高效地编辑文本。

## 2. 第一章：基础操作

### 1.1 基础光标移动

```
          ↑
          k
      ← h   l →      h — 向左移动
          j           l — 向右移动
          ↓           j — 向下移动（形似向下箭头）
```

使用 `h`、`j`、`k`、`l` 键移动光标。方向键也可以使用，但 `hjkl` 离其他按键更近，操作更快。

### 1.2 退出 Helix

1. 输入 `:` 进入命令模式（Command mode），光标将移动到屏幕底部
2. 输入 `q` 或 `quit` 并回车退出

> **注意**：如果有未保存的更改，`q` 会失败。使用 `q!` 或 `quit!` 强制退出并**丢弃**更改。
> 按 `Escape` 退出命令模式。

### 1.3 删除

按 `d` 键删除光标下的字符。

示例：
```
--> Thhiss senttencee haass exxtra charracterss.
     This sentence has extra characters.
```
将光标移动到多余字符上按 `d` 删除。

### 1.4 插入模式

按 `i` 键进入插入模式。

1. 将光标移动到缺少文本的位置，按 `i` 进入插入模式
2. 输入缺失的文本
3. 按 `Escape` 退出插入模式，返回普通模式

> **提示**：状态栏会显示当前模式，输入 `i` 后 `NOR` 会变为 `INS`。

### 1.5 保存文件

- 输入 `:w` 或 `:write` 保存文件
- 输入 `:wq` 或 `:write-quit` 保存并退出
- 可以在 `w` / `write` 后跟文件路径，保存到指定路径

> **提示**：如果有未保存的更改，文件名旁会显示 `[+]`。

### 第一章回顾

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 光标移动 | `h` / `j` / `k` / `l` | 左/下/上/右 |
| 命令模式 | `:` | 进入命令模式 |
| 退出 | `:q` / `:quit` | 退出（有未保存更改时失败） |
| 强制退出 | `:q!` / `:quit!` | 强制退出，丢弃更改 |
| 保存 | `:w` / `:write` | 保存文件 |
| 保存退出 | `:wq` / `:write-quit` | 保存并退出 |
| 删除字符 | `d` | 删除光标所在字符 |
| 插入模式 | `i` | 进入插入模式 |
| 返回普通模式 | `Escape` | 退出插入模式 |

## 4. 第三章：移动与选择

### 3.1 移动与选择

按 `w` 向前选择到下一个单词开头。

> `d` 键实际上删除的是**所有选中的文本**。光标本身就是一个单字符的选择区。

### 3.2 更多移动命令

| 命令 | 说明 |
|------|------|
| `w` | 向前移动到下一个单词开头 |
| `e` | 向前移动到当前单词结尾 |
| `b` | 向后移动到当前单词开头 |

提示：结合 `e` 和 `b` 可以选择光标所在的整个单词。

### 3.3 单词与 WORD

`w`、`e`、`b` 还有大写版本 `W`、`E`、`B`，用于遍历 **WORD** 而非 word。

- **word** — 由空白字符和其他字符（如标点）分隔
- **WORD** — 仅由空白字符分隔

示例：`one-of-a-kind` 是一个 WORD（1 次按键遍历），但包含 7 个 word。

```
--> Helix is a one-of-a-kind "modal" text editor
```

### 3.4 修改命令

按 `c` 修改（change）当前选择区。

`c` = 删除选择区 + 进入插入模式，相当于 `d + i` 的快捷方式。

### 3.5 带计数的移动

在移动命令前输入数字可重复执行多次。

- `2w` — 向前移动 2 个单词
- `3e` — 移动到第 3 个单词的结尾
- `2b` — 向后移动 2 个单词

### 3.6 选择模式

- 按 `v` 进入选择模式（Select mode）
- 在选择模式中，每次移动会**扩展**选择区（而非替换）
- 再按 `v` 或 `Escape` 返回普通模式

### 3.7 选择整行

- 按 `x` 选择当前整行
- 再按 `x` 选择下一行
- 按 `X` 选择当前行（**不会**扩展到后续行）

### 3.8 折叠选择区

- 按 `;` 将选择区折叠为单个光标
- 按 `Alt-;` 翻转选择方向（交换光标和锚点）

### 第三章回顾

| 命令 | 说明 |
|------|------|
| `w` | 向前选择到下一单词开头 |
| `e` | 选择到当前单词结尾 |
| `b` | 向后选择到当前单词开头 |
| `W` / `E` / `B` | 同上，但按 WORD 为单位 |
| `d` | 删除整个选择区 |
| `c` | 删除选择区并进入插入模式 |
| `{数字} + 移动` | 重复移动指定次数 |
| `v` | 进入选择模式（移动扩展选择区） |
| `x` | 选择整行（再按扩展下一行） |
| `;` | 折叠选择区为单个光标 |
| `Alt-;` | 翻转选择方向 |

## 5. 第四章：撤销、复制与搜索

### 4.1 撤销与重做

- 按 `u` — 撤销（undo）
- 按 `U` — 重做（redo）

### 4.2 复制与粘贴

- 按 `y` — 复制（yank）选择区
- 按 `p` — 在光标后粘贴
- 按 `P` — 在光标前粘贴

> **注意**：
> - 删除或修改文本时，Helix 会自动复制被更改的文本
> - 使用 `Alt-d` / `Alt-c` 可避免这种行为
> - Helix 默认**不**共享系统剪贴板
> - 按 `Space + y` / `Space + p` 使用系统剪贴板复制/粘贴

### 4.3 文件内搜索

- 按 `/` — 向前搜索，回车确认
- 按 `?` — 向后搜索
- 按 `n` — 转到下一个匹配项
- 按 `N` — 转到上一个匹配项

> **提示**：搜索支持正则表达式。与 Vim 不同，`?` 不会改变搜索方向，`N` 始终向后，`n` 始终向前。

### 第四章回顾

| 命令 | 说明 |
|------|------|
| `u` | 撤销 |
| `U` | 重做 |
| `y` | 复制（yank） |
| `p` | 在光标后粘贴 |
| `P` | 在光标前粘贴 |
| `Space + y` / `Space + p` | 使用系统剪贴板复制/粘贴 |
| `/` | 向前搜索 |
| `?` | 向后搜索 |
| `n` / `N` | 下一个/上一个匹配项 |

## 6. 第五章：多光标与选择命令

### 5.1 多光标

- 按 `C` — 将光标复制到下一行合适的行
- 按 `Alt-C` — 将光标复制到上一行
- 按 `,` — 移除第一个光标

多光标让你可以同时在多个位置进行编辑，非常适合批量修改。

### 5.2 选择命令

按 `s` 在选择区中选择匹配项。

1. 按 `x` 选择整行
2. 按 `s`，输入要匹配的文本并回车
3. 所有匹配项都会被选中，然后可以修改

### 5.3 正则选择

选择命令支持正则表达式，不仅仅是精确匹配。

示例：选择行后按 `s`，输入 `  +`（匹配连续多个空格），然后全部替换为单个空格。

> **提示**：这是 Helix 中查找替换的标准方式。先按 `%` 选择整个文件，然后使用 `s` 命令。

### 5.4 对齐选择区

按 `&` 对齐选择区的内容。

多光标选中多个行后，按 `W` 选择需要对齐的部分，再按 `&` 即可对齐。

> `&` 只关心选择区的"头部"（移动的一端）的对齐，另一端称为"锚点"。

### 5.5 按行拆分选择

按 `Alt-s` 将选择区按换行符拆分为多个选择。

适用于对齐表格等场景：

```
| FRUIT   | AMOUNT |
|---------|--------|
| Apples  | 8      |
| Bananas | 6      |
```

1. 用 `x` 选择所有行
2. 按 `Alt-s` 拆分为每行一个选择
3. 按 `&` 对齐

### 第五章回顾

| 命令 | 说明 |
|------|------|
| `C` | 向下复制光标到下一行 |
| `Alt-C` | 向上复制光标到上一行 |
| `s` | 在选择区中按模式选择 |
| `&` | 对齐选择区 |
| `Alt-s` | 按换行符拆分选择区 |
| `,` | 移除第一个光标 |

## 7. 第六章：字符查找与替换

### 6.1 定位到字符

| 命令 | 说明 |
|------|------|
| `f<字符>` | 向前查找到并包括该字符（find） |
| `t<字符>` | 向前查找到但不包括该字符（till） |
| `F<字符>` | 向后查找到并包括该字符 |
| `T<字符>` | 向后查找到但不包括该字符 |

> **提示**：与 Vim 不同，Helix 不限制这些命令在当前行，它会在整个文件中搜索。

### 6.2 替换命令

按 `r<字符>` 将所有选中的字符替换为指定字符。

示例：选中 `=` 分隔符后按 `r-` 替换为 `-`。

### 6.3 重复操作

- 按 `.` — 重复上一次插入操作
- 按 `Alt-.` — 重复上一次 `f` / `t` 选择操作

### 第六章回顾

| 命令 | 说明 |
|------|------|
| `f` / `F` | 向前/向后选中到并包括指定字符 |
| `t` / `T` | 向前/向后选中到但不包括指定字符 |
| `r` | 替换选中的字符 |
| `.` | 重复上一次插入操作 |
| `Alt-.` | 重复上一次 f/t 选择操作 |

## 9. 第八章：寄存器与宏

### 8.1 寄存器

寄存器是由字符标识的容器，用于存储复制的文本、最近的搜索词和宏。

- 按 `"<字符>` 选择寄存器 `<字符>`
- 默认寄存器是当前用到的那个

示例：`"by` 将文本复制到寄存器 `b`，`"bR` 用寄存器 `b` 的内容替换。

### 8.2 宏

宏是录制一系列操作以便重复使用的功能。

| 命令 | 说明 |
|------|------|
| `Q` | 开始录制宏（默认录制到 `@` 寄存器） |
| `Q`（再次） | 停止录制 |
| `q` | 回放宏（从默认的 `@` 寄存器） |

可用 `"<寄存器>Q` 将宏录制到指定寄存器。

### 第八章回顾

| 命令 | 说明 |
|------|------|
| `"` | 选择不同的寄存器 |
| `Q` | 开始/停止录制宏（默认寄存器 `@`） |
| `q` | 回放宏（从 `@` 或所选寄存器） |

## 10. 第九章：搜索与跳转

### 9.1 搜索选择区

按 `*` 将当前选择区复制到 `/` 寄存器，即设置搜索词为当前选择的内容。

然后可以用 `n` / `N` 在匹配项间跳转。

> 相当于 `"/y` 的快捷方式。

### 9.2 在下一个搜索匹配处添加选择

在**选择模式**（`v`）下使用 `n` / `N` 时，不会移动选择区，而是在每个匹配处添加新的选择区。

1. 选择文本按 `*` 设置搜索词
2. 按 `v` 进入选择模式
3. 按 `n` 添加其他匹配项的选择
4. 用 `c` 或 `r` 修改

### 9.3 使用跳转列表

Helix 会记录"跳转"（大幅移动，如搜索或跳转到函数定义），存储在跳转列表中。

| 命令 | 说明 |
|------|------|
| `Ctrl-s` | 手动保存当前位置到跳转列表 |
| `Ctrl-i` | 在跳转列表中向前移动 |
| `Ctrl-o` | 在跳转列表中向后移动 |

### 9.4 双字符标签跳转

按 `gw` 启用双字符标签。每个单词开头会被替换为两个高亮字符：

1. 按 `gw` 启用标签
2. 输入任意两个高亮字符跳转到对应位置
3. 按 `Escape` 取消标签

非常适合在可视范围内快速跳转。

### 第九章回顾

| 命令 | 说明 |
|------|------|
| `*` | 将主选择区设为搜索词 |
| `v` + `n` / `N` | 在选择模式下为每个搜索匹配添加选择 |
| `Ctrl-s` | 保存位置到跳转列表 |
| `Ctrl-i` / `Ctrl-o` | 跳转列表中向前/向后移动 |
| `gw` | 启用双字符标签跳转 |

## 12. 第十一章：注释

### 11.1 注释单行

- 按 `Ctrl-c` — 注释光标所在行
- 再按 `Ctrl-c` — 取消注释

### 11.2 注释多行

使用选择区和多光标功能，选中多行后按 `Ctrl-c` 即可注释所有选中行。

> **注意**：如果选择区中已有注释行，它们不会被取消注释，而会被再次注释。

### 第十一章回顾

| 命令 | 说明 |
|------|------|
| `Ctrl-c` | 注释/取消注释光标所在行 |
| 选择 + `Ctrl-c` | 注释多行（已注释的行不会被取消注释） |

## 13. 第十二章：匹配模式

匹配模式用于处理括号对及其内容。从普通模式按 `m` 进入匹配模式（Match mode）。

### 12.1 使用匹配模式跳转

- 按 `mm` — 跳转到匹配的成对括号

示例：将光标放在 `(` 上按 `mm`，跳转到匹配的 `)`。

### 12.2 选中括号内内容

- 按 `mi(` 或 `mi)` — 选中括号内的所有内容（不含括号本身）
- 同样适用于 `[]`、`{}`、`""` 等

### 12.3 选中括号及内容

- 按 `ma(` 或 `ma)` — 选中括号及其内的所有内容（含括号本身）

### 12.4 添加包围符号

1. 选中文本
2. 按 `ms(` 或 `ms)` — 用括号包围选择区
3. 同样适用于 `'`、`"`、`{`、`[` 等

### 12.5 删除包围符号

1. 将光标放在括号对内的任意位置
2. 按 `md(` 或 `md)` — 删除周围的括号对

> 尝试删除不存在的包围符号时，底部会显示错误信息。

### 12.6 替换包围符号

1. 将光标放在括号对内的任意位置
2. 按 `mr([` — 将 `()` 替换为 `[]`

> 替换不存在的包围对时会显示错误信息。

### 第十二章回顾

| 命令 | 说明 |
|------|------|
| `m` | 进入匹配模式 |
| `mm` | 跳转到匹配的成对括号 |
| `mi(` | 选中括号内的内容（不含括号） |
| `ma(` | 选中括号及内容（含括号） |
| `ms(` | 用括号包围选择区 |
| `md(` | 删除周围的括号 |
| `mr([` | 将 () 替换为 [] |

## 14. 第十三章：分屏操作

### 13.1 创建新分屏

按 `Ctrl-w` 打开窗口菜单：

| 命令 | 说明 |
|------|------|
| `Ctrl-w nv` | 新建垂直分屏（右侧） |
| `Ctrl-w ns` | 新建水平分屏（下方） |

### 13.2 在分屏间移动

| 命令 | 说明 |
|------|------|
| `Ctrl-w k` | 移动到上方分屏 |
| `Ctrl-w j` | 移动到下方分屏 |
| `Ctrl-w h` | 移动到左侧分屏 |
| `Ctrl-w l` | 移动到右侧分屏 |
| `Ctrl-w w` | 按打开顺序移动到下一个分屏 |
| `Ctrl-w q` | 关闭当前分屏 |
| `Ctrl-w o` | 关闭除当前外的所有分屏 |

### 13.3 分屏当前缓冲区

- `Ctrl-w s` — 水平分屏显示当前缓冲区
- `Ctrl-w v` — 垂直分屏显示当前缓冲区

### 13.4 使用命令分屏

- `:vsplit <文件名>` 或 `:vs <文件名>` — 垂直分屏打开文件
- `:hsplit <文件名>` 或 `:hs <文件名>` — 水平分屏打开文件

### 13.5 交换分屏位置

从分屏中按 `Ctrl-w` + 大写字母交换位置：

| 命令 | 说明 |
|------|------|
| `Ctrl-w K` | 与上方分屏交换 |
| `Ctrl-w J` | 与下方分屏交换 |
| `Ctrl-w H` | 与左侧分屏交换 |
| `Ctrl-w L` | 与右侧分屏交换 |

### 13.6 转置分屏方向

按 `Ctrl-w t` 转置分屏方向（垂直 ↔ 水平）。

### 13.7 从文件选择器打开分屏

1. 按 `Space f` 打开文件选择器
2. 模糊搜索文件
3. 按 `Ctrl-v` — 在垂直分屏中打开选中文件
4. 按 `Ctrl-s` — 在水平分屏中打开选中文件
5. 按 `Escape` 退出文件选择器

### 第十三章回顾

| 命令 | 说明 |
|------|------|
| `Ctrl-w` | 访问窗口和分屏命令 |
| `Ctrl-w hjkl` | 在分屏间移动 |
| `Ctrl-w q` | 关闭分屏 |
| `Ctrl-w o` | 关闭除当前外的所有分屏 |
| `:vs <文件>` | 垂直分屏打开文件 |
| `:hs <文件>` | 水平分屏打开文件 |
| `Space f` + `Ctrl-v` | 从文件选择器垂直分屏打开 |
| `Space f` + `Ctrl-s` | 从文件选择器水平分屏打开 |
